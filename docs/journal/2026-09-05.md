## @Vaild

`@Vaild`를 붙인다고 해서 바로 검증하는 것이 아니다.

해당 객체와 그 하위의 객체에 선언된 **Bean Vaildation 규칙(@NotNull, @Positive, @NotEmpty 등)을 검증하도록 요청하는 역할**을 한다.

```java

public class OrderRequest {

    @NotEmpty
    private List<OrderItemRequest> items;
}
```

현재 구조에서 보면, Controller의 @Valid가 OrderRequest로 던지고, OrderReuqest의 @Valid가 그 하위 OrderItemRequest로 던져서 그 안의 @NotNull이나 @Positive을 검증할 수 있다.

```
Controller
   |
   | @Valid
   v
OrderRequest
   |
   | @Valid
   v
List<OrderItemRequest>
   |
   +-- @NotNull productSeq
   +-- @Positive quantity
```

`@NotNull`,`@Positive` 는 `@Valid`에 의한 요청 DTO 검증 실패 결과를 Spring MVC가 `MethodArgumentNotValidException`으로 처리한다.
