# 에러 코드 규칙

`CustomException`이 클라이언트에게 내려주는 `code` 값의 규칙이다.
enum 정의는 `src/main/java/com/truthgarnet/shopping/common/ErrorCode.java`에 있다.

## 형식

```
{도메인 2글자}{3자리 숫자}
예) PD001, OD001
```

## 도메인

| 접두어 | 도메인 | 비고 |
|--------|--------|------|
| `PD` | 상품 (Product) | |
| `OD` | 주문 (Order) | |
| `CM` | 공통 (Common) | 특정 도메인에 속하지 않는 에러 |

## 분류 기준

**"어디서 던졌는가"가 아니라 "무엇에 대한 에러인가"로 나눈다.**

예) `PRODUCT_NOT_FOUND`는 `OrderService`에서 던지지만, 존재하지 않는 것은 상품이므로 `PD`다.
이 기준을 쓰는 이유는 같은 에러가 여러 서비스에서 던져지더라도 코드가 흔들리지 않게 하기 위함이다.

## 번호 규칙

- 도메인별로 `001`부터 순차 증가한다.
- **삭제된 번호는 재사용하지 않는다 (영구 결번).**
  클라이언트가 코드 값으로 분기하고 있을 수 있기 때문에, 같은 번호가 다른 의미로 재등장하면 안 된다.
- 새 코드는 해당 도메인의 마지막 번호 + 1로 추가한다.

## 현재 코드 목록

> `ErrorCode.java`를 수정하면 이 표도 함께 갱신한다.

| 코드 | enum | HttpStatus | 의미 |
|------|------|------------|------|
| `CM001` | `INVALID_INPUT` | 400 Bad Request | 요청 본문의 유효성 검증 실패 (`@Valid`) |
| `PD001` | `PRODUCT_NOT_FOUND` | 400 Bad Request | 요청한 상품이 존재하지 않음 |
| `OD001` | `OUT_OF_STOCK` | 409 Conflict | 주문 수량이 재고보다 많음 |
